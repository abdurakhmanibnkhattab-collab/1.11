# Контроль термопечей — исходный проект Android

Первая версия проекта для Android Studio (Kotlin + Jetpack Compose).

## Что реализовано в каркасе
- 8 печей с редактируемыми названиями (по умолчанию «Печь 1» … «Печь 8»).
- Независимый таймер для каждой печи.
- Ввод времени в часах и минутах; отсчёт начинается сразу после нажатия «Запустить».
- Повторяющийся звуковой сигнал после окончания времени до подтверждения «Выгружено»; если ожидают несколько печей, сигнал прекращается только после подтверждения всех.
- Состояние таймеров сохраняется локально; незавершённые таймеры восстанавливаются после перезагрузки телефона.
- Нет журнала истории.

## Как открыть
1. Установите Android Studio.
2. Откройте папку проекта `HeatFurnaceControl`.
3. Дождитесь синхронизации Gradle.
4. Запустите на Android-телефоне или соберите APK через Build → Build APK(s).

## Важные замечания перед эксплуатацией
Это стартовый прототип, а не сертифицированная промышленная система. На разных моделях Android производитель может ограничивать фоновые сигналы и точные будильники. При первом запуске разрешите уведомления; в настройках Android разрешите приложению точные будильники, если система попросит. Проверьте работу на конкретном телефоне, в том числе при заблокированном экране и после перезагрузки.

Сигнал уведомления зависит от настроек канала уведомлений Android. Для гарантированного слышимого оповещения настройте для канала «Окончание обработки» громкий звук и не отключайте уведомления. Приложение не управляет печами и не является защитной системой оборудования.

## Повторяющийся сигнал
При окончании таймера запускается foreground service с циклическим системным сигналом. Подтверждение «Выгружено» прекращает сигнал, когда не осталось других печей, ожидающих выгрузки. На Android/HiOS необходимо проверить работу службы и разрешить уведомления, автозапуск и фоновую работу. Если пользователь принудительно остановит приложение или система ограничит службу, сигнал может прерваться; обязательна проверка на целевом устройстве.


## Обновление интерфейса и сигнала (версия 1.1)
- Время задаётся одним числовым полем в минутах.
- Добавлен выбор мелодии: сигнал будильника, мелодия звонка или звук уведомления (доступные системные варианты устройства).
- Фоновый сервис использует воспроизведение с назначением AUDIO USAGE_ALARM и частичный WakeLock, чтобы звук не зависел от погашенного экрана.
- Если время истекло, но событие ещё обрабатывается, вместо нулевого таймера отображается «ЗАВЕРШЕНИЕ…».

Обязательно проверить на конкретном TECNO/HiOS: заблокированный экран, режим «Не беспокоить», громкость будильника, ограничения фоновой работы и одновременное завершение нескольких таймеров. Android и прошивка производителя могут ограничивать фоновые службы; приложение не является сертифицированной системой промышленной безопасности.
